Esta pasta contem os icones usados pelas marcacoes do minimapa do client Tibia.

O app usa os arquivos `0.png` ate `19.png` automaticamente ao importar `minimapmarkers.bin`.

Mantenha exatamente estes nomes:

- `0.png`
- `1.png`
- `2.png`
- ...
- `19.png`

Tambem existe `reference.html` para conferir rapidamente qual ID corresponde a cada arquivo.
